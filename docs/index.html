CUSTOMATE

Customs Document Automation

Prepare customs letters. Review every detail.

1. Upload document

Choose a Word document with Part Number, Description, Function, and Detail Picture rows. Letter details are preserved.

2. Review all items

Use Search images to find a suitable photo, then paste or drag it into the image box. Review the Indonesian descriptions before downloading. Word font follows your template; English part names and material terms are italicized. Review all drafts before downloading.

3. Download document

Review the results. Missing images will remain blank in the Word document.

Install CUSTOMATE

Desktop / Android: open the browser menu and choose Install app or Add to Home screen. On iPhone / iPad: open in Safari, tap Share, then Add to Home Screen.

Use Save progress before closing to keep your edits. Upload the same Word template before restoring progress.
